#  Legal AI Assistant using RAG

##  Project Description
This project is a Legal AI Assistant built using Retrieval-Augmented Generation (RAG). It helps users get relevant legal information based on queries like FIR, fraud, cybercrime, and consumer rights.

---

##  Features
- RAG-based document retrieval
- TF-IDF embeddings
- Cosine similarity search
- Legal risk detection system (Unique Feature)
- Streamlit web interface

---

##  Technologies Used
- Python
- Streamlit
- NLP (TF-IDF)
- RAG concept

---

```bash
pip install -r requirements.txt
